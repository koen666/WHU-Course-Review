# WHU 课程复习资料公开

> 为了让同学们面对陈年老旧的ppt少走歪路

武汉大学计算机学院课程复习资料整理与分享项目。本仓库包含多门核心课程的复习资料、代码实现和学习笔记。


## 📝 贡献指南

欢迎同学们贡献自己的复习资料！

- 提交 Pull Request 前请确保资料准确性
- 代码请保持良好的注释和格式
- 新增课程请在 README 中更新目录

## ⚠️ 注意事项

- 本仓库资料仅供学习交流使用
- 请勿直接抄袭代码，理解原理更重要
- 复习资料可能存在错误，欢迎指正
- 考试时请遵守学术诚信

## 📧 联系方式

如有问题或建议，欢迎提 Issue 或 Pull Request。
